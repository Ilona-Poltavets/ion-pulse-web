# Goals

Цель: развить редактор журнала, читалку и редакционные инструменты.
Исключено: хранилище картинок в облаке.

## Редактор журнала
- [x] Автосборка с настройками (число страниц, рубрики, приоритет)
- [x] Умная раскладка: чередование шаблонов страниц, фотостраницы-открывашки
- [x] Лента миниатюр всех страниц с перетаскиванием (и Alt + стрелки)
- [x] Undo / redo правок (Ctrl+Z / Ctrl+Y)
- [x] Автосохранение черновика (локальная копия + серверное сохранение)
- [x] Экспорт выпуска в PDF (печать A5, «Сохранить как PDF»)

## Контент
- [x] Импорт по ссылке с атрибуцией: только заголовок/описание/ссылка, текст не копируется
- [x] Подбор свободных изображений (Wikimedia Commons) с лицензией и автором
- [x] Теги и привязка материала к игре, страница игры
- [x] Сводная оценка игры по обзорам

## Читатели
- [x] Закладки и «прочитать позже»
- [x] Поиск по материалам с фильтрами (рубрика, игра, тип, оценка, тег, сортировка)
- [x] Подписки на игры (кнопка на странице игры)
- [x] Тема оформления (бумага / сепия / ночь) и размер шрифта в читалке
- [x] Звук листания (синтезируется) и тап по краю страницы

## Редакция
- [x] Календарь публикаций
- [x] Статистика просмотров, рубрик и топ материалов
- [x] Заметки редакции к выпуску (с привязкой к странице)

## Качество
- [x] E2E-тесты редактора, читалки и поиска (Playwright, `npm run test:e2e`)
- [x] Диагностика системы для администратора (БД, миграции, очереди, uploads)

## Найдено и исправлено по пути
- Читалка журнала падала на прямой ссылке `/journal/:id/read` (не было `GET /journal/issues/{id}`).
- Свайп в читалке перехватывался выделением текста.
