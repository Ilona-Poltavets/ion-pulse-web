# История изменений Ion Pulse

Формат основан на Keep a Changelog. До первого релиза все изменения записываются
в секцию `Unreleased`, а при релизе переносятся под версию и дату.

## Unreleased

### Added

- Создан основной документ продукта и план разработки `PROJECT.md`.
- Создан словарь предметной области `CONTEXT.md`.
- Зафиксированы двуязычная модель публикаций, RBAC, редакционный workflow,
  переводы, еженедельный журнал и дайджест.
- Создан новый каркас Vue 3 с TypeScript, Router, Pinia и Vitest.
- Добавлены локализованный RU/EN-интерфейс, переключение языка и стартовая
  страница Ion Pulse.
- Добавлены API-клиент, индикатор доступности backend и unit-тесты состояния.
- Настроены Vite, ESLint, Oxlint, Prettier и проверка типов.
- Добавлены web-экраны регистрации и входа, управление сессией и выход.
- Добавлена страница профиля с отображением ролей и изменением имени.
- Добавлена подача заявки на роль автора из профиля.
- В профиле отображаются собственные материалы и доступна отправка черновика
  редактору; после сохранения редактор возвращается в профиль.
- Автор может открыть существующий черновик, изменить его и сохранить через API.
- Добавлена редакционная очередь: редактор или администратор может опубликовать
  материал, отклонить его или вернуть на доработку с комментарием.
- Добавлены публичная лента и страница публикации: локализация с fallback на
  оригинал, пользовательская оценка и базовые комментарии.
- Редактор черновика показывает историю ревизий и позволяет восстановить версию;
  восстановление создаёт новую ревизию, не изменяя историю.
- Существующие черновики автоматически сохраняются после короткой паузы во вводе,
  создавая новую ревизию только на фактическую остановку редактирования.
- В редакционной очереди можно запланировать публикацию на конкретные дату и время.
- В редакторе доступен предпросмотр материала в читательском представлении до
  сохранения или отправки редактору.
- В профиле доступна подписка на игры из управляемого редакцией каталога.
- Читатель может пожаловаться на материал или комментарий; для модератора и
  администратора добавлена очередь жалоб с решениями и скрытием комментария.
- Очередь модерации показывает контекст жалобы и позволяет временно заблокировать
  автора цели с указанием срока.
- В профиле автора отображается статус ИИ-проверки для каждого материала.
- Главная страница перестроена вокруг ленты: фильтры по категориям, первый экран
  с опубликованными материалами, быстрый переход к созданию и рабочая навигация.
- Профиль переработан в рабочий кабинет: статусы материалов и ИИ-проверок,
  действия по черновикам, роли, заявка автора и подписки на игры.
- Редактор материала переработан в полноценный рабочий экран с метаданными,
  большим полем текста, состоянием автосохранения и боковой историей ревизий.
- Редакционная очередь получила компактный список материалов с раскрываемой
  областью чтения и явным состоянием обработки решения.
- Очередь модерации приведена к тому же рабочему формату: раскрываемые жалобы,
  контекст цели и действия по решению или санкции.
- Административная очередь заявок авторов получила обработку ошибок, состояния
  сохранения и рабочий формат раскрываемых заявок с портфолио и комментарием.
- Для редактора добавлен экран ручной редактуры готового перевода с сохранением
  происхождения `human` и переходом к нему со страницы публикации.
- На странице публикации добавлены одноуровневые ветки ответов к комментариям.
- Главная лента и редактор материалов получают видимые категории из API вместо
  захардкоженного списка.
- Контент-менеджер и администратор получили экран управления двуязычными
  категориями, их порядком, цветом и публичной видимостью.
- В редакторе доступны типы материалов, а для ревью — выбор игры из каталога и
  авторская оценка.
- Редакторы, модераторы и администраторы могут собрать ручной дайджест из
  опубликованных материалов; на странице дайджеста показан упорядоченный список
  выбранных публикаций.
- Добавлен редакторский экран недельных кандидатов журнала с расшифровкой
  рейтинга по оценкам и видимым комментариям.
- На экране кандидатов редактор, модератор или администратор может выбрать
  материалы, назвать и опубликовать выпуск журнала.
- В кабинете доступна выгрузка собственных данных и материалов в JSON.
- В кабинете добавлено подтверждённое паролем удаление аккаунта с пояснением
  последствий деактивации и псевдонимизации профиля.
- В очереди модерации добавлен разбор обжалований блокировок: модератор может
  одобрить обращение со снятием санкции либо отклонить его с обязательной причиной.
- На странице материала читатель может подписаться на автора, а в кабинете —
  просмотреть такие подписки и отписаться.
- Публичный журнал получил адаптивный режим чтения: обложку, оглавление,
  линейные карточки материалов и переходы между выпусками.
- Добавлены страницы запроса восстановления доступа и задания нового пароля;
  результат запроса не раскрывает существование email-адреса.
- В рабочей очереди модератора появился список скрытых комментариев с действием
  восстановления.
- Публикации получили отдельные RU/EN URL, динамические canonical и hreflang
  ссылки для двух локализаций.
- Добавлена публичная форма обжалования блокировки: она подтверждает email и
  пароль, самостоятельно находит активную санкцию и не требует её ID.
- Экран управления ролями показывает аудит последних назначений и отзывов.
- Локализация интерфейса охватывает профиль, создание материалов, ручную редактуру
  переводов, редакционную очередь, модерацию, категории, заявки авторов и роли;
  язык меняется через единый выпадающий список.
- Для локальной демонстрации добавлены пять опубликованных RU/EN-материалов и пять
  тестовых учётных записей.
- Фоновый worker постоянно обрабатывает плановые публикации, ИИ-проверки и
  переводы; добавлены шаблоны systemd-сервисов для API и worker.
- Добавлен Nginx-шаблон same-origin deployment: SPA, API proxy и TLS-граница.

### Changed

- Проект переименован в Ion Pulse.
- Корневая рабочая папка переименована из `habr` в `ion-pulse`.
- Локальная папка frontend переименована из `habr-clone-vue` в `ion-pulse-web`.
- GitHub-репозиторий переименован из `habr-clone-vue` в `ion-pulse-web`.
- Production-сборка web по умолчанию обращается к API на текущем origin, а не к
  `localhost`.

### Removed

- Удалена прежняя реализация frontend для разработки новой системы с нуля.
